# 20261104 测试镜像与 2026.11.4 配套软件

本版把今天的 IMU 标定修复、配网热点恢复，以及 20261027 镜像之后的软件功能整合到一张新镜像。新镜像的烧卡启动和运动效果仍需现场验收，因此作为测试版发布。

## 今天新增、修复了什么

| 项目 | 这次的行为 | 验证范围 |
| --- | --- | --- |
| 站姿下重新采 IMU 安装方向 | 模型关闭、HOME站稳、反馈新鲜时，可以保持站姿采静止和前倾；卸力后保留候选结果，再按提示核验保存 | 网页、后端测试及实机软件安装回读；本轮真实方向动作待验收 |
| ID 200 真实方向核验 | 主程序检查直立残差与前倾方向，通过后才保存；错误方向、无效姿态、超时和取消不保存 | 模拟总线、接口和故障回归；新镜像烧卡实测待验收 |
| 标定修正量显示 | 网页显示俯仰、横滚和总改变量，说明静止参考姿态的偏差也会折入安装方向 | 浏览器与后端回归 |
| IMU 数据检查 | 检查有效四元数、数据新鲜度、重复序号和计数连续性；提供原始数据诊断 | 协议、模拟总线和回归测试 |
| 换 Wi-Fi 后恢复热点 | 限制旧网络连接重试，并显式加载恢复用的热点配置；与舵机、IMU是否齐全无关 | 配网自动化；真实换网仍待验收 |

站姿采数不会自动启动运动模型。保存新方向前仍按页面提示托稳、卸力；这一步会保留已经采好的候选。

## 相对 20261027 完整镜像，补齐的已有功能

- 手柄按键重新映射，摇杆、扳机校准和配置保存。
- 摄像头卡片在原位置放大、还原，按实际画面比例显示。
- SSH 连接指引，解释网页密码和主板登录密码的区别。
- 音乐文件添加、选择、删除和独立播放；动作控制与音乐播放分开管理。
- 本地语音坐下、站起，动作录制回放，以及已有的语音配置入口。
- 嘴巴 ID 34、头部偏航 ID 32 的图示、点选与引线修正。
- IMU 和舵机独立诊断、秦墨手动配置适配、签名软件更新与回退。

这些属于此前的软件更新，此次才一起预装进新版完整镜像，不是都在今天重新开发。

## 完整四元数与小板固件

主程序支持显式选择配套的完整四元数通路。新镜像默认仍使用兼容旧小板的输出格式，不会自动刷写小板，也不会因为地址为 ID 200 就假定所有板卡的安装方向相同。

今天试过的 1.1 实验固件和 PC 端烧录验板工装属于另一条交付链路。工装显示烧录读回一致，只说明 Flash 校验通过，不代表姿态、通信和运动已经验收。1.2 补偿实验不作为本版默认固件。

固定安装方向预设、个人模型和个人标定不放进通用镜像。固定预设按本次讨论留待后续；目前也不宣称前后走、翻滚或倒地起身问题已经解决。

## 怎样使用

新卡下载 [20261104 测试镜像](https://github.com/fanhao375/microduck-replica/releases/tag/microduck-replica-image-20261104)，核对 SHA256 后烧录，再按首次开机、配网、舵机零位和 IMU 方向流程设置自己的鸭子。

已有可用系统卡的用户，可在 [2026.11.4 配套软件发布](https://github.com/fanhao375/microduck-replica/releases/tag/microduck-software-v2026.11.4) 下载完整 `.software-update.tar`，在“设置 → 软件更新”上传；驱动按页面提示独立处理，保留模型、标定及个人资料。此前已经装过 31 版配套驱动的，先按页面的“恢复旧配套驱动”流程处理，详见 [原生组件更新说明](native-update-20261104.md)。测试版可能不出现在默认稳定版更新列表中。

配套软件包更新 IMU、主控和网页；本次热点恢复补丁随新镜像提供，不能把上传软件包当作已经更新旧卡的系统配网组件。

出厂镜像清除维护者的 Wi-Fi、SSH身份、个人API Key、音乐、动作和标定，保留各组件原许可与模型说明。源代码、构建输入、附件哈希及测试范围随发行记录提供；离线检查不等于烧卡和实机运动验收。

已完成的构建、自动化与 GitHub 附件回读见 [发布验收记录](发布验收-20261104.md)。
