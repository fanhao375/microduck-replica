## 四、打印件

**30 种 / 41 件。**

**有 9 种要打多份：**

| 零件 | 打几个 |
|---|---|
| `leg_腿部` | **×4** |
| `hip_l_髋部左` | ×2 |
| `neck_颈部` | ×2 |
| `power_support_电源支架` | ×2 |
| `sole_left_左脚底` | ×2 |
| `sole_right_右脚底` | ×2 |
| `upper_leg_rigidity_plate_上腿加固板` | ×2 |
| `yaw2roll_偏航转横滚` | ×2 |
| **`bearing_roll_横滚轴承压盖`** | **×2** ← 见下方勘误 |
| 其余 21 种 | 各 ×1 |

> ⚠️ **勘误（2026-09-04）**：`bearing_roll` 此前被本仓库归入「标准件-无需打印」，**这是错的**。
> 判据：① 实测 23×3×40 mm 平板、带 Ø≈18 中心孔，不是任何标准轴承的形状（真轴承是回转体）；
> ② 与 `trunk_base` / `yaw2roll` / 外壳出自同一个 Onshape Part Studio；
> ③ 装配上与 `yaw2roll` 同 body、同位置，是贴在其侧面的一块盖板。
> 中译「轴承滚轮」也错了 —— 它既不是轴承也不是滚轮，已改为「横滚轴承压盖」。
> 打印件计数因此从 29 种 / 39 件更正为 **30 种 / 41 件**。

⚠️ **别搞混左右**：`upper_leg_left` 与 `upper_leg_right` 是镜像件
（质心 **±0.006766 m ＝ ±6.77 mm**），两个都要打；
`ankle_left`/`ankle_right`、`sole_left`/`sole_right`、`foot_left`/`foot_right` 同理。

## 未验证项

- 全部价格、销量、店铺信息与链接有效性（2026-09-04 快照）
- 螺丝长度按孔深推算，**是区间不是实测值**；FDM 打印收缩还会改变实际孔径
  （Ø2.2 通常偏小 0.1–0.3 mm）
- TPU 件的判断来自命名与用途，官方未标注材料
- `lens` / `m12_lens_holder` 的采购/打印归属
