# HD-1910 M6 参数来源与应用

2026-09-24：本项目采用 **LuwuDynamics 公开的 1910 BAM M6 动力学参数**，作为
HD-1910 仿真训练的初始模型。感谢 LuwuDynamics 的分享。参数不是本项目自行
辨识或测量的结果；本项目目前做的是接入和验证，实机测试由维护者后续进行。

的舵机参数；只有以后独立辨识得到的新参数，才可另行标注为本项目辨识结果。

## 怎么用

- 参数文件原样保存，保留 `model: "m6"` 和 `actuator: "sts3215"`；后者选择
  BAM 的飞特控制器实现。上游把型号写作 HLS1910，维护者已确认采用同款 1910。
- 配套训练设置：P=5、电压随机范围 7.4–8.0 V、压降下限 7.0 V、延迟 3–6 个
  仿真步。`max_velocity=100` 用于放开目标斜率限制，并不是舵机真实空载转速。
- 新增独立的 `Mjlab-Velocity-{Flat,Rough}-MicroDuck-HD1910` 训练入口，便于与
  原 XL330 基线比较。当前接入保留本地 Microduck 几何、关节顺序和默认姿态。
- 实机逐关节零位、方向和限位仍使用本项目校准结果；不复制对方整机的编码器
  零位或现成 ONNX 作为可直接上机的策略。

## 当前验证边界

公开参数使我们可以开始仿真接入，不再把完整自建辨识台架作为启动仿真的前置。
本项目尚未用实机验证这组参数。还需核对本机增益、供电、响应延迟、质量惯量、
IMU 和主控通信时序；先用小幅阶跃响应比较仿真与实物，再决定是否重新辨识。

原先[训练前数据清单](HD-1910训练前数据清单.md)里的 M3 客户参考值仍保留作历史
比较；当前新增的训练基线使用这里注明来源的 M6 参数。
