# 总线 IMU 自动识别 · 20261023c

本版把 DXL 2.0 IMU 兼容接入实际 robotd 运行程序、标定流程和 Studio，镜像默认自动识别。
原来的舵机网页调试工具支持 DXL2，不等于运动主程序支持；本版同时更新这两层的交接信息。

## 支持范围

| 连接方式 | 支持内容 | 选择方式 |
|---|---|---|
| Feetech 舵机总线，ID 200 | FT6 和兼容 IMU-to-DXL 的 Feetech 固件、56/15 数据块 | 自动识别身份与回复顺序 |
| 同一条 Feetech 舵机总线，ID 200 | DXL 2.0 协议、124/12 SFLP 数据布局 | 只读识别身份并检查数据布局，然后与 Feetech 舵机分开查询 |
| 主板 I²C | 原有 BNO08x / LSM6DSV16X | 沿用首次开机识别及显式配置 |

在 `[bus]` 中可以指定 `imu_protocol = "auto"`（默认）、`"feetech"` 或 `"dxl2"`。
固定协议时失败直接报错；运行中不偷偷换协议。不支持的寄存器格式、其他 ID 或波特率需要适配，
不会因为都叫 IMU 就全部通用。探测不修改芯片固件、ID、波特率或 EEPROM。

Studio 显示主程序报告的实际协议和布局。更换协议会使旧的采集/计算结果失效；
成功验证的安装方向保存协议绑定。旧版未记录绑定的总线标定按 Feetech 处理，
不能直接授权 DXL2 上力；页面仍可进入重标定。更换物理模块或装法后也需要重新校准。
DXL2 数据里没有的芯片计数器、状态位和芯片侧数据年龄保持缺省，页面不编造这些诊断值。

### 已核对的 ScrapMeta 总线固件

[ScrapMeta/microduck-diy 的 imu_to_dxl 固件](https://github.com/ScrapMeta/microduck-diy/tree/db04d323caa053ae0c96629268392cdbe7dc8b4f/imu_to_dxl/firmware)
已按固定提交 `db04d323caa053ae0c96629268392cdbe7dc8b4f` 核对。其默认契约为 DXL 2.0、
ID 200、1 Mbps、地址 124 的 12 字节块；身份字节为 `d8 27 01`（model 10200、firmware 1）。
陀螺仪为小端 i16，17.5 mdps/LSB；四元数 xyz 为小端 binary16，由主板重建 w。
这些格式已在 **20261023c 交付镜像**中支持，无需为此更换 robotd 或重新制作同内容的镜像。

本次将对方未修改的 `dxl_slave.c`、`dxl_crc.c`、`control_table.c`、`imu_pack.c` 编译成主机端
测试对端，通过伪串口与交付版 robotd 所用的实际 Rust `Bus`、解码器和新鲜度检查通信。
7 项交叉实现用例通过：自动识别、固定 DXL2、含转义字节的数据、全零未就绪、冻结、非法四元数
和坏 CRC；正常读取包含同一串口上的 15 颗模拟 Feetech 舵机。对方原有主机测试的 21 项断言
也通过。测试中没有另写一个 DXL2 应答模拟器来替代对方的协议实现。

本版只读取共同的 124/12 核心块；对方 `@136` 的 8 字节自定义诊断没有接入，不能套用飞特
或其他固件的状态位定义。探测仅确认协议/数据布局，不构成厂商或物理模块身份认证。
接好匹配的模块后，主控选择总线 IMU、保持 `imu_protocol = "auto"`，再完成舵机和 IMU 标定。
更换模块或装法后重做安装方向确认。

IMU 小板需预先烧好与其硬件匹配的固件。对方代码针对其 v0.3 STM32G031F8P6 + LSM6DSV16X
参考板；主板镜像不会自动刷写小板，也不代表其他同芯片板的引脚和缓冲器可以通用。
该子目录有独立 [MIT 许可证](https://github.com/ScrapMeta/microduck-diy/blob/db04d323caa053ae0c96629268392cdbe7dc8b4f/imu_to_dxl/LICENSE)。
本次只核验主板侧兼容，没有构建、分发或刷入对方 MCU 烧录文件；真实小板的持续总线读取、
标定、站立与运动仍待实机验收。

运行时提交为 `0791fcd44f71c705dc8bb0fbcde405593b52d19b`。对应构建、测试范围和镜像清单见 [20261023c 发布页](https://github.com/fanhao375/microduck-replica/releases/tag/microduck-replica-image-20261023c)。
