# Microduck 生态导航

**简体中文** · [English](ecosystem.en.md)

Microduck 的东西散在 GitHub 好几个组织和 HuggingFace 三种资源类型里，
**官方硬件仓库尤其容易被漏掉**（不在主仓，前缀是 `elec_`）。

这份索引说清楚每个东西**是什么、能拿来干嘛**。数据截至 **2026-09-04**，星数会变。

---

## 一、官方仓库（pollen-robotics）

### 核心两个

| 仓库 | 星 | 许可 | 这是什么 |
|---|---|---|---|
| [**microduck**](https://github.com/pollen-robotics/microduck) | 6982 | Apache-2.0 | **板载运行时**。Rust 写的，跑在机器人上的全部软件：50Hz 控制环、更新器、BLE、摄像头/WebRTC、ToF、语音。想读硬件规格也看这里 —— 设备路径、I²C 地址、寄存器全写死在代码里 |
| [**microduck_rl**](https://github.com/pollen-robotics/microduck_rl) | 1668 | Apache-2.0 | **强化学习训练环境**（基于 mjlab）。**47 个 STL 和完整 MJCF 在这里**，是所有几何信息的唯一来源 |

### 硬件（容易被漏的两个）

| 仓库 | 星 | 许可 | 这是什么 |
|---|---|---|---|
| [**elec_RPI_Robot_HAT**](https://github.com/pollen-robotics/elec_RPI_Robot_HAT) | 15 | Apache-2.0 | ⭐ **HAT 板的完整开源工程**。KiCad 9 原理图与 PCB、Gerber、BOM、贴片坐标、STEP、全套器件手册。**这块板不用自己画，下载 `production/` 直接打样**（4 层板） |
| [**lib_KiCAD**](https://github.com/pollen-robotics/lib_KiCAD) | 3 | — | Pollen 的 KiCad 符号/封装/3D 模型库。**打开上面那个工程必须先装它**，否则一片未解析符号 |

> 很多人以为「Microduck 硬件没开源」——**HAT 板其实是开源的**，只是不在主仓。
> 真正没公开的是 `imu_to_dxl` 板、可编辑机械 CAD 和整机 BOM。

### 配套

| 仓库 | 星 | 这是什么 |
|---|---|---|
| [rustypot](https://github.com/pollen-robotics/rustypot) | 56 | Dynamixel 通信库（Rust）。运行时靠它跟舵机说话，`xl330.rs` 里是完整寄存器表 |
| [microduck-gst-plugins](https://github.com/pollen-robotics/microduck-gst-plugins) | 13 | 预编译的 aarch64 GStreamer 插件：Rockchip MPP 硬件编码器 + WebRTC |
| `duck_detector` | — | ⚠️ **不公开**（404）。NPU 检测模型的训练仓库，官方文档里引用了它，但外部访问不到 |

## 从哪开始

| 你想做什么 | 去哪 |
|---|---|
| 先感受一下 | [官方网页模拟器](https://huggingface.co/spaces/pollen-robotics/microduck-simulator)，打开就能玩 |
| 看它长什么样、怎么装 | 本仓库 [`cad/`](../cad/) 和 [`assembly-drawings/`](../assembly-drawings/) |
| 打印零件 | 本仓库 [`print/`](../print/) |
| 搞懂电控 | 本仓库 [`docs/硬件方案逆向.md`](硬件方案逆向.md) |
| 做 HAT 板 | [`elec_RPI_Robot_HAT`](https://github.com/pollen-robotics/elec_RPI_Robot_HAT) 的 `production/`，别忘了先装 `lib_KiCAD` |
| 训自己的策略 | [`microduck_rl`](https://github.com/pollen-robotics/microduck_rl)；没有 N 卡就用 [microduck-lab](https://github.com/jonathanhawkins/microduck-lab) |
| 读硬件规格 | [`microduck`](https://github.com/pollen-robotics/microduck) 源码 —— **代码即规格书** |
