# 飞特舵机调试软件

配 ID、改参数、拉滑杆看舵机转 —— **就这两个文件，解压就能用，Windows。**

| 文件 | 干什么 | 版本 | 大小 |
|---|---|---|---|
| `FD1.9.8.5(250729).7z` | **FD 调试软件**。配 ID、开过流过压保护、拉滑杆测舵机 | 1.9.8.5（2025-07-29），中英文可切换 | 167 KB |
| `CH340_URT.rar` | **USB 转串口驱动**。**URT-2 用不上** —— 它是 CH343，Win10/11 自带驱动，插上就有 COM 口（实测 2026-09-12）。老款 URT-1 是 CH340，不认串口才装这个 | — | 224 KB |

## 装法

```
1  插 URT-2 → 设备管理器「端口」里出现 USB-Enhanced-SERIAL CH343 (COMx)，记下号
   没出现才装 CH340_URT.rar（那是给老款 URT-1 的）
2  解压 FD1.9.8.5(250729).7z → 直接运行，不用安装
3  FD 里选那个 COM 口 → 波特率 1000000 → 点「打开」→ 点「搜索」
```

搜到舵机就通了。**怎么飞线、怎么供电、配 ID、改哪些参数、ID 对照表** —— 全在 [调试记录 · 舵机配置](../../调试记录.md#舵机配置--拿到货一步一步做)，一步一步。
