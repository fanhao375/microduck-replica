# Radxa ZERO 3W：烧录和第一次使用

本页适用于 **Radxa ZERO 3W**。主板丝印为 **Cubie A7Z** 时，使用 [A7Z 烧录与配网说明](../../radxa-cubie-a7z/image/README.md)。两种主板的下载入口见[按主板下载镜像](../../README.md#按主板下载镜像)。

> [20261027镜像](https://github.com/fanhao375/microduck-replica/releases/tag/microduck-replica-image-20261027)已公开并设为Latest，完成构建、解压只读与发行附件核验；本版新卡实物验收仍待完成。它预装网页软件升级与本地R3“坐下／站起来”；完成原标定/站稳流程后使用，见[软件更新与语音](../../docs/软件更新与语音使用说明-20261027.md)。已有卡以后通过组件升级保留自己的数据，不必为每个网页功能重烧。

照着做完，鸭子就能站、能走。全程用浏览器，不用 SSH、不敲命令。

> **镜像免费，只供个人学习和非商业复刻。** 里面的走路和动作模型是作者的个人非商业许可：
> 不得随 HAT、整机、套件等产品预装或分发，不要卖烧好的卡，也不能用于收费服务。
> 各部分的许可见镜像里的 `/usr/share/doc/microduck/`，发布页上也有同样的三份 txt。

## 1. 准备

- 一只装好的**飞特 HD-1910 版**鸭子：15 颗舵机 ID 配好、HAT 插好。原版 XL330 的鸭子不要用这个镜像。
  - 我们实测用的是 Radxa Zero 3W（无 eMMC）+ 32 GB microSD 卡，HAT 是 C1 版。
- 躯干 IMU，二选一：
  - **IMU 模块**（BNO085 或 LSM6DSV16X）四根线直接接主板：接 HAT 的 J5，或者 40 针的 27 / 28 脚。
    D1 版 HAT 自己在头里带了一颗 LSM6DSV16X（地址 0x6A），躯干模块要设成 **0x6B**。
    LSM6DSV16X 模块推荐这样装：模块的 x 轴朝下、z 轴朝鸭子前方（二号鸭就是这样装的）。照这个装，IMU 那一步可以直接跳过。
  - 或者舵机总线上的 IMU 小板（ID 200）：认不到模块时，主程序会去总线上找它。
    20261023c 起自动识别 FT6、本仓库 imu_to_dxl 的 Feetech 固件（0.2.0 起），以及使用 124/12 SFLP 布局的 DXL 2.0 固件。
    不是所有厂家的任意固件都兼容：其他寄存器格式、ID 或波特率需要适配；IMU 页会显示实际识别结果。
    更换 IMU 或安装方向后重新做方向校准，旧 Feetech 的方向确认不能直接用于 DXL2 上力。
  - **IMU 要在第一次开机之前接好**：第一次开机时鸭子会自己去认它。
- 一张 microSD 卡，8 GB 以上，推荐 32 GB；一个读卡器。
- 一台电脑（烧卡用），一部手机（配网用）。

## 2. 下载、核对、烧卡

1. 下载 `microduck-replica-日期.img.xz` 和同名的 `.sha256`（GitHub Releases 或网盘）。
2. 核对文件没下坏（可以跳过，但出了怪问题先查这个）：
   - Windows：在下载目录打开 PowerShell，运行 `Get-FileHash microduck-replica-日期.img.xz`，跟 `.sha256` 文件里的那串对一下（大小写不用管）；
   - Mac / Linux：`shasum -a 256 -c microduck-replica-日期.img.xz.sha256`。
3. 用 [balenaEtcher](https://etcher.balena.io/) 烧卡：选镜像文件（`.img.xz` 不用解压）→ 选 SD 卡 → Flash。
   用树莓派官方的 Raspberry Pi Imager 也行：「操作系统」选最下面的「使用自定义镜像」。
4. 烧完 Windows 可能弹「需要格式化」，点**取消**，别格式化。

## 3. 第一次开机

1. SD 卡插进主板，给鸭子上电（舵机电源也接上）。
2. 等 **3 分钟左右**。第一次开机要做三件事：把 SD 卡剩下的空间扩出来；给鸭子起个名字（`duck-` 加 4 位，比如 `duck-c51b`）；认 IMU 模块。以后开机就快了。
3. 鸭子连不上任何 WiFi 时（第一次开机一定是这样），会自己开一个热点：
   - 名字：`Microduck-` 加同样的 4 位，比如 `Microduck-c51b`；
   - 密码：`microduck`。

## 4. 手机连鸭子，配家里的 WiFi

1. 手机 WiFi 列表里找到 `Microduck-xxxx`，输入密码 `microduck` 连上。
   手机提示「此网络无法上网」时，选**保持连接**。
2. 手机浏览器打开 **http://10.42.0.1:8000/** ，看到 Microduck Studio。
   打不开的话，先把手机的**移动数据关掉**再试（有的安卓手机会绕开没网的 WiFi）。
3. 最上面是「连 WiFi」卡片：点你家的 WiFi，填密码，点「连接」，看清确认框里的话，再点「断开去连「你家 WiFi」」。
   每次连都要填密码，「已保存」的网络也一样。
4. 鸭子会关掉热点去连你家 WiFi，**手机会断开，这是正常的**。
5. 手机（或电脑）连回家里的 WiFi，按设备打开（xxxx 就是热点名字里那 4 位）：
   - **Windows 电脑**：**http://duck-xxxx:8000/**（不带 `.local`，开着 Clash 之类的代理也能打开）；
   - **苹果手机、Mac**：**http://duck-xxxx.local:8000/**；
   - **安卓手机，或者上面都打不开**：去路由器的管理页面，在设备列表里找 `duck-xxxx`，用它的 IP 打开，比如 `http://192.168.1.23:8000/`。
   - 打开以后，「更多」页里有这只鸭子现在的所有地址，可以加个书签。
6. 密码填错、或者鸭子没连上：热点会自己回来（一般马上，最慢 2 分钟左右）。再连 `Microduck-xxxx`，卡片上会用红字写上次为什么没连上，改了再试。

不想连家里 WiFi 也行：一直连着鸭子的热点用 Studio，所有功能都能用。

**安全提醒**：热点密码大家都知道，Studio 默认又没有登录密码，所以**附近的人连上热点就能控制鸭子**。
在外面演示之前，去 Studio 的「更多」页设一个登录密码。

**没有 WiFi 的户外用法**（手机说话 + 手柄）见 [Studio 的离线说明](../studio/deploy/OFFLINE.md)：
手机连 `Microduck-xxxx` 后打开 `https://10.42.0.1:8000/m`，按提示装鸭子的证书，就能用板载 Vosk 识别「手机说话」；实体手柄蓝牙直连，不需要 WiFi。

## 5. 照「上手清单」走

总览页有一张「上手清单」，从上往下做。每一步都有三个按钮：「去做」带你去对应的页面；以前做过的（比如舵机零位早就校过）点「已完成」；想先不做的点「跳过」。主程序说这一步还没做完的，点「已完成」或「跳过」时会提醒一句后果，确认了就算数。

1. **舵机零位**：去舵机页，把鸭子摆成零位（腿伸直、头摆正、嘴闭上），点「一键校准」。
2. **IMU 方向**：去 IMU 页做粗校：双手托起鸭子、摆正、别动，然后照页面提示往前低头。
   页面算出方向以后交给主程序再验一遍：摆正，然后 **20 秒内往前低头 15～30°**。
   主程序验过了，方向就记下了。
   - **更准的做法：站着校准**。IMU 页点「站姿使能」，15 颗舵机会在 3 秒内一起转到站姿并锁住（标定模式下也能站，
     只是不管平衡，要扶着点）。站住以后做「站着校准」（静止、前、后、左、右），做完点「失能」或顶上的「卸力」，扶住鸭子。
     算出来的方向第 3 步一起写进主程序。粗校没做也能站着校。
   - **以前校过、或者想先跳过**：点「已完成」或「跳过」，第 3 步会按默认装法写 IMU 方向：
     总线 IMU 小板用官方装法；BNO085 用 fork 的默认装法；LSM6DSV16X 用复刻推荐装法（模块 x 轴朝下、z 轴朝前）。
     装得不一样的，站起来会往一边倒：照上面做一次站着校准，再写一次主程序。
3. **写进主程序**：把上面两步的结果一次写进主程序。写之前让鸭子**坐着或者软着**（站姿使能站着的，先点「失能」），舵机电源要开着。
   写完主程序会重启（约 20 秒，慢的话一分钟），从标定模式切到运动模式，**扶好鸭子**。
   主程序没认这份标定的话，会自动换回原来的，页面上写原因。
   以后开机直接就能站、能走，不开网页也行。
4. **配手柄**：去手柄页按向导配蓝牙手柄。也可以先用网页上的手柄。
   雷神 G50 Pro 这类能切平台的手柄，背面拨 **X 档（Xbox）**：20261021b 上 X 档一下就连上；S 档（Switch Pro）配对能成功，但主程序收不到按键，手柄等一会儿会自己关机（原因还在查）。
5. **测急停**：**短按**一次手柄的 Select，确认鸭子能马上卸力。（按住 Select 2 秒是坐下、卸力、**关机**，测急停时别按住。）
6. **站起来、走几步**：点「站起来」，再点「开始走」，推摇杆。

任何时候想让鸭子马上软下来：点页面右上角红色的「卸力」，或者按空格键。

## 6. 手柄怎么按

按 Xbox 手柄的位置说：

| 按键 | 干什么 |
|---|---|
| Start | 第一次按站起来，再按开始走 / 停下 |
| 左摇杆 / 右摇杆 | 走 / 转 |
| Select 短按 | 马上卸力（急停） |
| Select 按住 2 秒 | 坐下、卸力、关机 |
| 十字键下 | 坐下 / 站起 |
| 十字键右 | 重启全部舵机 |
| A（下面那颗） | 低头捡东西 |
| X（左边那颗） | 前滚翻 |
| LB / RB | 左脚踢 / 右脚踢 |
| Y / B | 头部模式 / 身体姿态 |
| 扳机 | 张嘴 |
| 十字键上按住 3 秒 | 走路和轮滑之间切换（要装被动轮滑组件，普通鸭子别按） |

第一次试前滚翻和踢球时，给鸭子周围留出空间。每个动作对应哪个模型，见镜像里的 `/usr/share/doc/microduck/模型说明.txt`。

## 7. 出问题了

- **看不到 `Microduck-xxxx` 热点**：
  - 鸭子已经连上你家 WiFi 时不开热点，直接用 `http://duck-xxxx.local:8000/` 或路由器里的 IP 打开；
  - 第一次开机多等 2 分钟；还没有就断电重开一次。
- **页面打不开**：确认手机连的是鸭子的热点（或者跟鸭子在同一个 WiFi），地址末尾有 `:8000`；安卓手机关掉移动数据再试。
- **电脑开着 Clash 之类的代理**：`.local` 地址会被代理接走、打不开（报 502）。Windows 改用 `http://duck-xxxx:8000/` 或者 IP；
  开了 TUN 模式还打不开的，在代理软件里把局域网（192.168.0.0/16、10.0.0.0/8）设成直连，或者在绕过列表里加上 `*.local`。
- **IMU 那一步说「主程序还没报用的是哪颗 IMU」**：多半是第一次开机时没认到模块。检查接线和地址（D1 版 HAT 上躯干模块要 0x6B），
  然后用 SSH 运行 `sudo microduck-firstboot --detect-imu-only --force`，再重启鸭子。
- **求助**：Studio 的「更多」页（电脑上也可以去「日志」页）点「导出诊断包」，把文件发到群里，并说一下卡在哪一步。
  诊断包里有鸭子的序列号和局域网 IP，介意的话私发。

## 8. 进阶（不需要也能用）

- **SSH 远程登录**（出了问题自己登进去修，不用重烧卡）：Studio「更多」页的「SSH 远程登录」。
  先在上面设好网页登录密码，再**自己定一个 SSH 密码**（至少 8 位，不能是 `microduck`），点「打开 SSH 密码登录」。
  卡片上会写登录命令，比如 `ssh radxa@duck-xxxx`：Windows 打开 PowerShell、Mac 打开终端运行它，输刚设的密码。
  这个密码也是鸭子上 `sudo` 用的密码。不用了就点「关掉 SSH 密码登录」，回到只认钥匙。
  出厂时 SSH 只认钥匙、不认密码，镜像里**不带任何人的钥匙**，也没有能远程登录的默认密码。
- **本机登录**（接显示器和键盘）：用户名 `radxa`，默认密码 `microduck`，root 不能登录。登录后用 `passwd` 改掉。
- **登记 SSH 钥匙**（不用密码，更安全）：同一张「SSH 远程登录」卡片的「办法二」。
  还没有钥匙的话，Windows 在 PowerShell 里运行 `ssh-keygen -t ed25519`，一路回车；
  再运行 `type $env:USERPROFILE\.ssh\id_ed25519.pub`（Mac：`cat ~/.ssh/id_ed25519.pub`），把打出来的那一整行贴进去，点「登记这把钥匙」。
  **只贴 `.pub` 那个**，另一个是私钥，别给任何人。登记过的钥匙列在卡片上，能删。
- **Studio 登录密码**：在「更多」页设。也可以在鸭子上用 radxa 运行 `python3 -I /home/radxa/studio-dev/run.py set-password`，**别加 sudo**（加了 Studio 会读不了密码文件）。
  没设过密码时，谁打开 Studio 都能设第一个密码，所以出门演示前自己先设好。
- **忘了登录密码**：SSH 登录鸭子，删掉密码文件 `/var/lib/microduck-studio/password.json` 或 `/home/radxa/studio-dev/state/password.json`（哪个在删哪个），再运行 `sudo systemctl restart microduck-studio`，就回到没密码的状态。
- **接了摄像头**：镜像默认用测试画面，没接摄像头的鸭子也不会报错。接了摄像头的，把 `/etc/robot/robotd.toml` 里 `[media]` 段的 `source = "test"` 改成 `source = "camera"`，再运行 `sudo systemctl restart mediad`。
- **两个默认行为要知道**：电池电压低了**不会自动关机**，只在页面上警告，看到警告就停下充电，别把电池放光；
  鸭子摔倒以后**不会自动卸力**，扶起来之前先按 Select 或者点「卸力」。
- **HTTPS 证书 / 手机麦克风**：第一次开机生成局部 CA（`/etc/microduck/tls/`），Studio 自动用 HTTPS 起。
  旧的鸭子可以用 `sudo microduck-firstboot --tls-only` 迁移；手机怎么装证书、没有 WiFi 时怎么用，见 [Studio 的离线说明](../studio/deploy/OFFLINE.md)。
- **镜像里带了什么、许可证**：鸭子上的 `/usr/share/doc/microduck/` 目录，或者 [镜像构建说明](README.md#镜像里有什么)。
