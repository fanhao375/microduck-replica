# 中控原型：功能补漏与布局统一

本轮版本：`20261108-15`。对照原 Studio 本地源码与本仓库 A7Z 跟踪模块；本记录是离线原型的展示、操作与状态检查，不是实机验收。

## 设备管理布局

- 舵机与关节、IMU 与姿态、运行诊断改为遥控页同款顶部横向标签，移除设备页左侧分类栏。
- 舵机零位参考与 IMU 三维区向左扩展。1440px 时三维区与主内容同为 x=244；舵机参考约492px宽，IMU约592px宽。
- 1024px、390px 检查未发现整页横向溢出；390px下三项标签在同一排。
- 保留用户指定的行内松开、保持、中位和就地详情；没有恢复独立中位页、批量标定或“更多标定操作”。

## 本轮补齐

### 首页与共用状态

- 统一显式演示 telemetry，在线数、最热舵机、CPU与姿态展示使用同一来源，未提供字段显示未知。
- 首页补手柄/急停、IMU待验证/采集/待提交、模型选用/加载、供电等摘要。
- 装机检查仅保留一个入口，删除重复常用跳转与固定的“已保存”历史。
- 交还失败与标定未写入的提示合并；软件重连只显示一条统一进度入口，更新页由自己的阶段卡承接。

### 舵机、维护与诊断

- 姿态设置折叠内补跟随拖动、头部灵动及独立停止；固定零位模型继续只作参考。
- 补62项逐地址寄存器快照、JSON下载和Markdown复制；未知值为null，写入演示显示原值、写入值、读回值，详情共用该状态。
- 扫描区分found/lost；时序保留min/avg/p99/max/fails字段，无串口测量的数据保持空。
- 补通信统计与启动状态字段。历史异常跟踪记录分列卸力确认和参数恢复，异常记录不参与差值。
- 浏览器发现切换寄存器会关闭填写区，已为寄存器、临时P/D、姿态设置及舵机参数保留展开状态。

依据：原 `web/servo.js:139,248-254,373-389`、`studio/bus/feetech.py:26`；本仓库 `tracking/web/leg-tracking.js:137-147`。

### 遥控、录制与感知

- 手柄配对补类型选择、搜索结果、取消/重搜、连接、19项按键及双摇杆反馈、完成与忘记。
- 补持续嘴声、连续滚翻、条件接管、轮滑长按与缺模型拒绝。
- 补录制/回放继续的连接、交还、提交、更新及配置变化门禁；空录制不产生草稿，暂停归中，离开视口停止相应活动。
- 离线软停只确认网页输出已清理，设备状态仍待确认；恢复连接后仍需明确站姿确认才可走。
- 合并录制、停止、叫声和相机预览重复按钮；口令细目放折叠，ToF补频率。

依据：原 `web/pad.js:150,505,1054,1258`、`studio/motion_studio.py:517,764`、`web/voice.js:81`、`web/sensors.js:259`。

### 模型、网络、账号与设置

- 模型补刷新、加载/选用区分、按用途门禁、详情改键、删除和恢复确认；未知兼容导入仍不可选用。
- WiFi同一弹窗整合手动SSID、开放网络、显示密码、重扫与密码校验，保留换网找回阶段。
- SSH公钥校验与SHA256指纹去重，仅保留元数据；密码入口合并。AI保留非敏感草稿、登录前置、测试失败、五轮试聊及清空语义。
- 更新每阶段仅一个主按钮，保留离线包入口、非空/160MiB限制、失败保留包、版本读回及有历史才显示的恢复。
- 档案、电池与舞台背景区分未修改、未保存和生效值，三个舞台主题实际应用到三维区域。

依据：原 `web/models.js:136-141,240-257,408-415,456-464`、`studio/models.py:198-215`、`web/wifi.js:308-380`、`studio/sshkeys.py:15-59`、`web/settings-ai.js:44-103`、`web/settings-updates.js:29-61`、`web/tune.js:288-300`、`web/settings-battery.js:66-72,143-145`、`web/styles.css:22-43`。
