## 首次启动向导（2026-11-08，v17）

总览只保留一张首次启动卡，展示当前一步、简短说明和一个主按钮。连接 → 设备检查 → 15 颗舵机零位 → IMU 方向与站姿校准 → 统一提交及模型加载检查 → 停止测试 → 首次迈步。操作仍在设备和遥控页，顶部短引导在任务完成后提供下一步；舵机与 IMU 的重复提交入口在向导期间合并。

默认使用网页遥控，实体手柄是停止测试时的可选分支。点击“开始走”不算完成，必须在有效站姿与动力状态下观察到非零走路输入。手柄分支以明确标注的“演示轻推手柄”完成模拟输入。校准改动使旧提交与急停凭证失效，修改舵机零位还会作废旧站姿修正。

同一标签页刷新可保留演示进度；不会恢复上力、站姿或运动命令。未完成的提交恢复为待重试，损坏的保存内容回到干净的首次流程。`状态预览 → 首次装机` 可重新体验。

验证：`node --test tests/onboarding.test.cjs`；37 项状态测试。浏览器从零跑通网页和可选手柄两条演示分支，并核对刷新恢复、1440px/390px布局、总览一张卡且一个主按钮。这些不代表实机标定、蓝牙或行走验收。

## 已确认的范围

## 功能归属

- **设备总览** `#/overview`：姿态、近期回读、健康状态、常用入口、最近操作。
- **遥控与动作** `#/remote`：网页遥控、实体手柄、技能与叫声；动作录制、暂停、保存、改名、删除、回放及灵动。录制内容是控制指令与节奏，不能当作真实关节轨迹。
- **语音与视觉** `#/sensing`：相机预览、ToF 8×8 距离、语音控制与音频设备；AI 连接配置跳转系统设置。
- **设备管理** `#/devices`：舵机维护、中位标定、姿态存取、关节跟踪、高级工具；IMU 安装方向与站姿标定、提交；总线运行诊断。关节跟踪标明待板端安装。
- **模型中心** `#/models`：模型库、用途选择、导入与兼容信息、重命名、删除导入项、恢复内置、按键映射、机器档案与只读参数。遥控的按键设置进入同一处。
- **运行日志** `#/logs`：筛选、搜索、暂停、复制与诊断导出。诊断包导出只保留一个入口。
- **系统设置** `#/settings`：网络、账号与 SSH、AI 连接与文字试聊、电池、更新与恢复、显示偏好。

## 已发现的结构问题

旧中控的 `#/pad` 是总览长页锚点，总览同时挂载姿态、状态、上手清单、手柄、配对、动作与模型。设置则混合网络、AI、日志、模型机器档案等多个任务。

此次将完整操作移出总览；按使用任务划分一级页面，硬件和设置按子页进入。相机没有增加源码中未发现的人脸/物体检测或头部跟随能力。
