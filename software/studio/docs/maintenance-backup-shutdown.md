# 网页维护：备份、恢复和安全关机

增加桌面/手机备份恢复入口、顶栏安全关机与证书下载组件。维护接口要求已设置网页登录密码、有效会话；写操作还要求同源和 CSRF。恢复及关机要求显式确认，未安装助手时返回不可用。

1104 软件更新后，Studio 通过已有的 `/usr/local/sbin/microduck-helper` 调用当前签名包中的维护助手。四个固定动词分别用于导出、预览、恢复和关机。普通更新沿用现有 sudoers 规则。

助手只恢复固定白名单配置，不执行或覆盖备份附带源码。**相机设备树（`/boot/radxa-camera-8m-local.dtbo`）只导出、不通过网页恢复**，因为它由内核启动时加载；`robotd.toml` 恢复时只允许当前文件已有的配置项，备份不能带进新项。恢复要再输入一次网页登录密码；软件更新或 IMU 标定进行中，恢复和关机都会被拒绝。恢复成功后只保留最近 2 份恢复前的旧配置，其余删除（里面有 API Key）。校验 ZIP 路径、成员数量、解压大小及清单 SHA256；清单校验不等同数字签名，只导入可信来源的备份。恢复前保留当前配置备份，写入失败尝试回滚；恢复会重启相关服务。

备份可能包含已保存的 API Key、设备配置与主机名，属于私密文件，不要提交或公开分享。网页密码及浏览器会话不包含在内。上传原始 ZIP 上限 16MB，JSON/Base64 请求上限 24MB。

关机先停止并卸力，等待确认后才安排系统关机。提取时收紧卸力判断：不能用一项否定反馈覆盖仍上力或过渡中的状态。本次只运行模拟授权、确认、白名单、校验及扭矩门禁测试，没有执行真实恢复、服务重启或关机；部署与不同镜像兼容仍需真机验证。
