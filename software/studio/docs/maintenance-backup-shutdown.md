# 网页维护：备份、恢复和安全关机

增加桌面/手机备份恢复入口、顶栏安全关机与证书下载组件。维护接口要求已设置网页登录密码、有效会话；写操作还要求同源和 CSRF。恢复及关机要求显式确认，未安装助手时返回不可用。

管理员需将 `deploy/microduck-maintenance` 安装到 `/usr/local/sbin/microduck-maintenance`，root 所有、0755。用 `visudo` 仅授权 Studio 服务用户运行此固定路径的 export、preview、restore、shutdown 四个操作；不要授权任意参数、任意路径或 shell。Python 需支持 tomllib，系统依赖 sudo、systemd、fdtoverlay（恢复相机设备树时）。服务运行账号及安装路径需按目标镜像核对。

助手只恢复固定白名单配置，不执行或覆盖备份附带源码。校验 ZIP 路径、成员数量、解压大小及清单 SHA256；清单校验不等同数字签名，只导入可信来源的备份。恢复前保留当前配置备份，写入失败尝试回滚；恢复会重启相关服务，相机设备树可能需要重启整机。

备份包含 AI/TTS Key、设备配置与主机名，属于私密文件，不要提交或公开分享。网页密码及浏览器会话不包含在内。上传原始 ZIP 上限 16MB，JSON/Base64 请求上限 24MB。

关机先停止并卸力，等待确认后才安排系统关机。提取时收紧卸力判断：不能用一项否定反馈覆盖仍上力或过渡中的状态。本次只运行模拟授权、确认、白名单、校验及扭矩门禁测试，没有执行真实恢复、服务重启或关机；部署与不同镜像兼容仍需真机验证。
