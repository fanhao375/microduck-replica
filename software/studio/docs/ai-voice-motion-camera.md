# 手机 AI 语音、表情动作与视觉交互

依赖源仓库 TTS PR #61。手机语音页默认使用本地固定口令。切换到 AI 对话后，可使用已保存的语音默认模型或手动选择连接；手机录音经现有 `/api/asr?free=1` 转文字，再请求模型。麦克风需 HTTPS、浏览器授权以及设备已有的 ASR 服务，不包含新的 ASR 云端供应商。文字输入也可使用。

设置页可显式启用 AI 动作工具。动作执行检查运动模式、扭矩、策略、控制权与卸力标记；语音播放失败或停止后取消后续动作。嘴部和头部使用独立通道，身体动作等待语音结束；开启动作工具后，自动朗读可在扭矩和归位已确认时带动嘴部，已有运动策略时还可轻转头。普通朗读不会自行开启行走策略，扬声器试听只播放示例。此功能会驱动硬件，首次使用需承托设备并验证急停。

每次发送前可勾选「允许本次对话向所选模型发送摄像头画面」打开本地预览，并允许模型请求一帧。发送后授权自动清空。视觉工具经本机 mediad 获取画面并传给本次选择的模型；需要支持视觉的模型和工作中的摄像头。手机和桌面对话展示本次传给模型的图片，预览沿用现有同源媒体信令。首次预热 12 秒，已有预览时等待 3 秒。图片及语音识别文字可能发送到用户选择的模型提供商并消耗额度；Key 不进入提示词。

提取时不包含备份恢复、关机、IMU 或曝光修改。使用模拟 RPC、音频和摄像头进行回归，不以软件测试代替真机电机/麦克风/相机验收。
