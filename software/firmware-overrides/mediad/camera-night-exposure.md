# mediad 夜间曝光源码补丁

此目录仅提供 `night-exposure.patch`，不包含固件二进制。需在与补丁上下文相符的外部固件源码树中应用，然后按原固件构建流程编译、部署 mediad；更新 Studio 网页不会改变媒体曝光。

改动：目标亮度 90→115；硬曝光上限 1200→1700 行（按上下文行时间约 32.4ms）；数字增益上限 16→32 倍。软曝光阈值及模拟增益上限保持原值。

提高亮度可能增加噪点、运动拖影，且长曝光接近帧周期。需在目标传感器上复核暗光可辨识度、帧率、运动画面和明暗切换。回退时恢复原 mediad 版本或反向应用补丁并重编译。

本次检查补丁语法和改动范围；仓库不含相应 mediad 源文件，未运行 Rust 构建或本次真机曝光测试。
